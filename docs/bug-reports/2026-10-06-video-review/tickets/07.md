Jobs currently presents a board switcher with Public board, All boards, and Create a board. Kris questions whether boards need to be visible in the discovery experience and proposes tags as a simpler filter.

### Source and requested behavior

Recording: **04:26–05:14 (shared discussion segment)**. Transcript excerpt (lightly normalized UI names):

> I don’t even know if we need boards. Maybe we could just have different tags, and then we could filter by those.

Evaluate a tag-based discovery interface that simplifies the board concept for users. This is a product/design proposal, not a demonstrated filtering malfunction.

### Reproduction / review steps

1. Open Jobs.
2. Open the Public board switcher.
3. Compare the board menu with the existing search and phase filters.

### Acceptance criteria

- [ ] Record whether tags replace visible board switching or complement it, and specify the intended tag taxonomy/selection behavior.
- [ ] Prototype tag filtering together with the current search and phase filters.
- [ ] Define URL persistence, empty results, and how tags are supplied for existing and newly created jobs.
- [ ] Account for tenant board policies and existing scoped URLs; a discovery redesign alone does not delete the underlying board protocol.
