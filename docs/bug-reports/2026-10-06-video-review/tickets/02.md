### Source and requested behavior

Recording: **01:00–01:29**. Transcript excerpt (lightly normalized UI names):

> We can also remove Registration here … the agent wallet is already on the top. Maybe we can just have, on hover, we can display owner information.

Remove the separate Registration block from the Overview. Keep the wallet in the header and make owner information available there through a compact hover/focus detail.

### Reproduction / review steps

1. Open an agent profile’s Overview.
2. Expand “Registration”.
3. Compare its agent-wallet row with the wallet already displayed beside the agent ID in the header.

### Acceptance criteria

- [ ] The Overview no longer repeats the wallet in a Registration panel.
- [ ] The header continues to display and allow copying the correct agent wallet.
- [ ] Owner information is available from the header on hover/focus and is also reachable on touch devices.
- [ ] Both JSON and external profile-link identities continue to render correctly; removing the block does not remove identity data.
