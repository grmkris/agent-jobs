## 1. Stake (wallet-paid)

1. Sign in at `/me`; record the connected address.
2. Open **Stake**, record Staked/Reserved/Available and the current fee tier.
3. Stake 20,000 FACTORY with the displayed permit flow. Capture the review and transaction. Confirm the tier changes from the live table.

## 2. Sponsorship (signed permission, then relay sends)

1. In **Me → Gas sponsorship**, review the relay, target contracts, allowed methods, call cap and expiry. The policy must exclude publish, approve, top-up, stake, requestUnstake and Safe/admin calls.
2. Sign once. Capture the enabled state and the operation key. Do not claim that signing is a transaction unless the UI shows a real upgrade transaction.

## 3. Request → quote → hire → payment

1. **Post** → title `K6 quote job`, brief `Write a 200-word changelog.` → **Request quotes**. Set **Quotes close in** to a value before the delivery deadline, then **Review → Ask for quotes**. This creates a request without escrow or a transaction.
2. Coordinator has W1 quote 3 mUSD and W2 quote 4 mUSD. Refresh, capture the comparison and choose **Pick** on W1 → **Pick this quote**. Before sending, coordinator reads the frozen request/offer windows and arbitrator; confirm token and reward in the review, approve if needed, then publish job B.
3. W1 reads `fee_quote`, activates through the relay, then waits while Kris uses **Add to the reward → 1 mUSD → Add** from the wallet. W1 submits only when Kris is ready to review.
4. Kris **Approve and pay → Send · Hireling pays the gas** promptly after submission. Record B's net payment and the creator bond release.
5. Explore's quote form omits window choices; the board uses Standard preferences (currently 24 h / 24 h / 48 h, clamped to deployment bounds). Smaller minimums do not shorten those preferences. The quote-close timer is a different clock. This sheet therefore pays B promptly and uses a separate Fast direct hire R in step 8 for the same-session rejection/refund; it no longer waits a day for B.
